# COM-Box — Конвертер BMS RS485 → CAN (Vision → Solis Pylontech LV)

Прошивка для апаратного шлюзу **COM-Box (GD32F305RCT6)**, яка опитує акумуляторні модулі **Vision (15S LiFePO4)** по шині RS485 та передає зведені дані та ліміти інвертору **Solis S6** по шині CAN за протоколом **Pylontech LV (`PYLON_LV`, 500 kbps)**.

## Основні можливості

* **Підтримка до 16 паралельних модулів** (автоматичне виявлення активних паків по RS485).
* **Дані в реальному часі:** напруга, сумарний струм (`+` заряд / `-` розряд), середній **SOC** та **SOH** напряму з регістрів BMS.
* **Динамічні ліміти:** автоматичний розрахунок `CCL` / `DCL` залежно від кількості активних модулів, температури та напруги комірок.
* **Апаратне керування профілем через DIP-перемикачі:**
  * **DIP1 `OFF` (за замовчуванням):** верхня межа заряду **54.0 В** (100% + автобалансування).
  * **DIP1 `ON`:** щадний режим **51.8 В** (без автобалансування).
  * **DIP5 `OFF`:** ліміт струму заряду **40 A** на один модуль.
  * **DIP5 `ON`:** ліміт струму заряду **50 A** на один модуль.
* **Захист:** передача аварій та попереджень (`0x359`), прапорців дозволу заряду/розряду (`0x35C`), апаратний watchdog (`FWDGT`).

## Підключення

### 1. Кабель CAN (COM-Box ↔ Solis S6 порт `BMS` RJ45)

Використовується стандарт **EIA/TIA 568B** (прямий обжим для пінів 4 і 5):

| Контакт RJ45 | Колір (568B) | Сигнал |
|---|---|---|
| **Pin 4** | Синій | `CAN-H` |
| **Pin 5** | Синьо-білий | `CAN-L` |

### 2. Шина RS485 (COM-Box ↔ Акумулятори Vision)

Підключення до порту RS485 майстер-акумулятора (або шини модулів) згідно з розпіновкою COM-Box.

## Налаштування інвертора Solis S6

У меню **Battery Setting** (або через додаток Solis Cloud) виставте:

* **Battery Type:** `Lithium Battery`
* **Battery Model:** `PYLON_LV` (або `Pylontech`)
* **Max Charge Current:** `100A` (або максимум інвертора — реальний ліміт задає COM-Box)
* **Max Discharge Current:** `100A` (аналогічно)
* **Over Discharge SOC:** `20%`
* **Recover SOC:** `30%`
* **Force Charge SOC:** `15%`
* **Max Charge SOC:** `100%`
* **Battery Saving:** `Enable`

Для заряду від мережі в **Storage Mode**: увімкніть **`Allow grid charging`** та задайте **Charge period** (наприклад, `00:00 – 23:59`, `100%`).

## Збірка та прошивка

### Збірка з вихідного коду (PlatformIO)

```bash
pio run
```

Після успішної збірки готові файли автоматично копіюються у:
* `compiled_firmware/` (`firmware.bin`, `firmware.hex`) — повний образ для прошивки через програматор (SWD / J-Link / ST-Link / UART).
* `compiled_firmware_app/` — образ з заголовком для завантажувача (якщо використовується bootloader).

### Прошивка

1. Підключіть програматор (SWD: `SWDIO`, `SWCLK`, `GND`, `3.3V`) або використайте вбудований завантажувач COM-Box.
2. Завантажте `compiled_firmware/firmware.bin` (або `.hex`) у мікроконтролер `GD32F305RCT6` (адреса старту `0x08000000` для повного образу).
3. Перезавантажте COM-Box та переконайтесь, що на екрані Solis з'явився статус **`BMS Comm OK`**.
